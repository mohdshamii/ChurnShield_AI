Production Retention & Inference API

Programmatic access for customer retention automation, CRM integration, real-time scoring, and monitoring telemetry.

v2.0 RESTful OpenAPI Spec
POST /api/predict
Single Customer Inference & Retention Analysis

Evaluates customer features across the Soft Voting Ensemble, outputs churn probability, financial CLV metrics, and personalized retention playbooks.

Sample Request Payload
{
  "customer_id": "CUST-9021",
  "tenure": 4,
  "MonthlyCharges": 89.5,
  "TotalCharges": 358.0,
  "Contract": "Month-to-month",
  "InternetService": "Fiber optic",
  "PaymentMethod": "Electronic check",
  "TechSupport": "No",
  "OnlineSecurity": "No"
}
Sample 200 OK Response
{
  "status": "success",
  "prediction_id": 142,
  "customer_id": "CUST-9021",
  "churn_probability": 0.7842,
  "churn_percentage": 78.4,
  "risk_level": "HIGH",
  "financial_clv_roi": {
    "annual_revenue": 1074.0,
    "revenue_at_risk": 842.23,
    "retention_roi_percent": 340.5
  }
}
POST /api/what-if
Counterfactual Intervention Simulation

Simulates the delta in churn probability between a customer baseline and an intervened scenario (e.g. upgraded contract or added tech support).

Request Body
{
  "baseline": { "Contract": "Month-to-month", "tenure": 2 },
  "scenario": { "Contract": "Two year", "tenure": 2 }
}
Response
{
  "success": true,
  "baseline_prob": 76.5,
  "scenario_prob": 18.2,
  "percent_risk_reduction": 58.3,
  "risk_mitigated": true
}
GET /api/models
Model Benchmark Matrix

Returns cross-validation and test set evaluation metrics across all registered champion and candidate models.

GET /api/monitoring/drift
Live PSI & Data Drift Telemetry

Returns Population Stability Index (PSI) scores, Kolmogorov-Smirnov distribution tests, and automated retraining signals.
